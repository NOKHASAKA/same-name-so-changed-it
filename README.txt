PRISTINE STARTER — HOW TO RUN

1. Extract pristine-starter.zip.
2. Open VS Code.
3. Choose File > Open Folder.
4. Select the extracted pristine-starter folder.
5. In VS Code, open index.html.
6. If you have the Live Server extension, right-click index.html and choose Open with Live Server.
   Otherwise, double-click index.html in Finder to open it in your browser (Live Server is recommended).
7. Keep all three files in the same folder.

IMPORTANT:
- This is a front-end starter/demo. It stores data in localStorage in this browser.
- It does NOT yet implement secure user registration/login, cloud database sync, or reliable offline caching.
- External ocean photos and Google Fonts need an internet connection.
- The starter includes basic local planner interactions: navigation, themes, quotes, calendar events, timetable sessions, habit tracking, moodboard uploads, and JSON export.
